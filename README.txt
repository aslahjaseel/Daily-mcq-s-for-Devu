DEVU'S DAILY QUIZ
=================
TEST IT: double-click index.html (works on any laptop, no internet needed).

PUT IT ONLINE FREE (GitHub Pages)
1. Make a free account at github.com.
2. Click + (top right) > New repository. Name it devu-quiz. Choose Public. Create.
3. Click "uploading an existing file". Drag in EVERYTHING from this folder
   (index.html, app.js, style.css, assets folder, days folder). Click Commit changes.
4. Settings > Pages > Source: "Deploy from a branch" > Branch: main, folder: / (root) > Save.
5. After about a minute your link is https://YOUR-USERNAME.github.io/devu-quiz/ . Send it to Devu.

EVERY DAY
1. Send Claude the day's notes with the prompt from PROMPT.txt.
2. Save the reply as days/YYYY-MM-DD.js (see days/_TEMPLATE.txt).
3. On GitHub open the days folder > Add file > Upload files > Commit. Done. No code changes ever.

Her results are saved in her own browser. Use "My results > Save a backup" now and then.
